### 2. Rotate Turtle to Face Its Swimming Direction

The turtle PNG is viewed from above.

The top of the original image should point in the direction that the turtle is travelling.

Currently, the turtle travels in a straight line between randomly generated entry and exit positions.

Use those positions to calculate its heading.

#### Required Behaviour

For example:

- Swimming directly right → top of turtle points right.
- Swimming directly left → top of turtle points left.
- Swimming diagonally down-right → top of turtle points down-right.
- Swimming diagonally up-left → top of turtle points up-left.

This must work for every randomly generated trajectory.

#### Implementation

Calculate the travel direction using the difference between the entry and exit coordinates.

Assuming the original PNG points upwards and screen coordinates increase downwards, an appropriate CSS rotation calculation is:

```js
const deltaX = endX - startX;
const deltaY = endY - startY;

const heading =
  (Math.atan2(deltaY, deltaX) * 180) / Math.PI + 90;
```

The exact implementation may differ depending on the existing component structure.

Requirements:

1. Calculate the turtle's heading for every swimming pass.
2. Rotate the image so its top edge points along that trajectory.
3. Set the heading before the turtle enters the visible area.
4. Keep that heading consistent throughout the crossing.
5. Do not rotate the turtle to face a different direction halfway through.
6. Preserve the straight-line swimming trajectory.

The heading rotation must work alongside the new wiggle animation.
