## 4. Replace Fixed Swimming Duration with Distance-Based Speed

### Objective

The turtle currently swims at an appropriate speed when moving horizontally.

I want this same perceived swimming speed to apply when it moves vertically.

Instead of applying the same duration to every journey, calculate the animation duration based on the journey's actual distance.

### Existing Horizontal Timing

Preserve the horizontal speed established in Epic-009 Bug-002.

**Homepage Hero**

Existing horizontal journey duration:

5–7 seconds.

**Page Links and Classes Hero**

Existing horizontal journey duration:

10–14 seconds.

These should remain the baseline for calculating swimming speed.

### 4.1 Calculate the Reference Swimming Speed

For each swimming pass, calculate a suitable baseline speed in pixels per second.

Use the existing horizontal movement as the reference.

The reference should account for the current section's dimensions and the distance of a representative horizontal crossing.

For example:

```js
const referenceDistance = Math.hypot(
  referenceEndX - referenceStartX,
  referenceEndY - referenceStartY
);

const referenceDuration = randomBetween(
  minDuration,
  maxDuration
);

const speed = referenceDistance / referenceDuration;
```

For Page Links and Classes Hero, `minDuration` and `maxDuration` are 10 and 14 seconds.

For Homepage Hero, they are 5 and 7 seconds.

**Important:** Use a representative horizontal crossing based on the actual section geometry, including the existing off-screen travel requirements.

Do not calculate speed from a completely unrelated fixed viewport dimension.

### 4.2 Calculate the Actual Journey Distance

Once a random trajectory has been selected, calculate its actual length.

Use the Euclidean distance formula:

```js
const deltaX = endX - startX;
const deltaY = endY - startY;

const distance = Math.hypot(deltaX, deltaY);
```

This works for:

- Horizontal movement.
- Vertical movement.
- Diagonal movement.

Both the starting and ending points must account for the turtle being completely outside the section boundaries.

### 4.3 Calculate the Swimming Duration

Use:

```js
const duration = distance / speed;
```

This produces the time required to cover the selected distance at the desired swimming speed.

Convert to milliseconds when passing the result to CSS or the Web Animations API.

- Distance: 1,200px.
- Duration: 12 seconds.

Swimming speed:

**100 pixels per second.**

Now suppose a new vertical trajectory is only 600px long.
