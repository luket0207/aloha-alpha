## Issue

The decorative images introduced in Epic-011 Feature-001 are too small on mobile.

I want them to be significantly larger, with different positioning rules depending on the decoration.

These changes apply only to mobile layouts.

## 1. Palm Tree and Surfboard

The Palm Tree in Kids Class and Surfboard in Third Class should both be positioned in the centre of their respective Class Sections.

### Size

Each image should be sized within two limits:

- Maximum height: 80% of its Class Section container's height.
- Maximum width: 80% of its Class Section container's width.

Whichever limit is reached first should control the final image size.

### Requirements

1. Preserve the image's original aspect ratio.
2. Scale the image as large as possible within both constraints.
3. Do not stretch or distort the image.
4. Do not allow either image to exceed 80% of the section's height.
5. Do not allow either image to exceed 80% of the section's width.
6. Recalculate sizing when the container dimensions change.
7. Support sections with different content heights.

For example, if the image would exceed the maximum permitted width before reaching 80% of the section height, use the width limit.

Avoid relying on percentage-based CSS image heights unless the containing block has a definite, correctly resolved height.

If necessary, use the existing measurement utilities or ResizeObserver to determine the actual dimensions.

### Positioning

Both images should be centred on the X and Y axes of their respective Class Sections.

Requirements:

1. Centre horizontally relative to the section.
2. Centre vertically relative to the section.
3. Do not centre relative to the viewport.
4. Do not centre relative to the featured-image element.
5. Preserve their final centred position after entrance animations finish.
6. Prevent decoration sizing or positioning from increasing the section's height.

Use a dedicated positioning wrapper so entrance rotation does not interfere with centring transforms.

### Mobile Opacity

Preserve the existing decorative opacity:

**0.2**

Both images must remain behind all normal content.

### Entrance Animations

Preserve the existing falling animations:

- Palm Tree — existing bottom-centre falling rotation.
- Surfboard — existing right-to-left falling rotation.

The animations should end at the new centred positions.

Do not remove the falling effects or introduce unnecessary movement.
